# scrubbed-workspace
Scrubbed Workspace helps you use AI in colaboration with sensitive emails.

This guide (README) is for **You**, and the [PLAYBOOK](PLAYBOOK.md) is for the AI agent.

## What you'll have:
1. emails automiticlly being copied and scrubbed locally.
2. A workspace your AI can read from that contains only processed email copies.
3. A private place to review messages the system isn't confident in.
4. A way to check, pause, and resume the workspace.

## Start here

1. Open Claude or your preferred coding agent. It needs to edit files and run
   commands on your computer. A chat-only model can help you get that set up first.
2. Paste the prompt below.
3. Answer its questions and follow the local sign-in or installation steps it
   explains. At the end, have it demonstrate the workspace and show you how to use it.

### Prompt to paste

```text
Read https://github.com/ZackHanson/scrubbed-workspace/blob/main/PLAYBOOK.md and set up a working Scrubbed Workspace for me. Create and organize the project folder yourself.
```
